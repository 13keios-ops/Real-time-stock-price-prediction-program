# Machine Learning Operations Plan

## 1. 목적

이 프로젝트의 머신러닝은 단순히 모델 하나를 학습시키는 것이 아니라, `실시간 데이터 -> 특징 생성 -> 예측 -> 모의투자 검증 -> 재학습`의 반복 루프를 운영하는 것입니다.

따라서 머신러닝 설계는 아래 세 가지를 동시에 만족해야 합니다.

1. 장중 예측이 가능한 속도여야 합니다.
2. 왜 그런 예측이 나왔는지 해석 가능해야 합니다.
3. 예측의 품질과 모의투자 성과를 함께 추적할 수 있어야 합니다.

## 2. 초기 머신러닝 전략

초기에는 복잡한 딥러닝 단일 모델보다 `트리 기반 베이스라인 + 이벤트 확장 + 메타 앙상블` 구조가 적합합니다.

### Layer 1. 가격/호가 베이스라인 모델

- 입력: 분봉, 거래량, 거래대금, VWAP 괴리, 호가 불균형, 스프레드
- 후보: LightGBM, XGBoost
- 대상: 15분 방향, 60분 방향

이 모델의 역할:

- 가장 먼저 안정적인 베이스 예측력을 확보
- 추론 속도와 해석성을 동시에 만족
- 실시간 운영 시 장애가 적음

### Layer 2. 이벤트/심리 특징 확장 모델

- 입력: 공시, 뉴스 건수, 검색량 변화, 반응량 프록시, 감성/주의집중 특징
- 후보: LightGBM 추가 특징 버전, 또는 텍스트 전용 점수 모델

이 모델의 역할:

- 가격 데이터만으로 놓치는 이벤트성 충격 보완
- 심리적 요인을 프록시 특징으로 반영

### Layer 3. 메타 앙상블

- 입력: Layer 1 점수, Layer 2 점수, 최근 성능 특징
- 후보: Logistic Regression, LightGBM calibration layer

이 모델의 역할:

- 개별 모델 점수를 결합
- 과도한 확신을 보정
- 운영 중 챔피언/챌린저 비교 용이

## 3. 왜 이 전략이 적합한가

1. 종목 수가 초기에는 30개로 크지 않아서 고속 복잡 모델이 필수는 아닙니다.
2. 실시간 운영과 자동 모의주문을 함께 할 때는 예측 안정성과 해석 가능성이 중요합니다.
3. 트리 기반 모델은 피처 중요도, SHAP, 오류 분석이 쉬워서 초기에 유리합니다.

## 4. 라벨과 학습 단위

### 라벨

- 15분: `+0.35% 이상 상승`, `-0.35% 이하 하락`, 그 외 중립
- 60분: `+0.8% 이상 상승`, `-0.8% 이하 하락`, 그 외 중립

### 학습 샘플 생성 시점

- 1분 단위 특징 스냅샷 생성
- 각 시점마다 15분/60분 라벨을 별도로 생성

### 제외 구간

- 장 종료 직전 예측 불가능 구간
- 거래정지/이상 이벤트 구간
- 데이터 누락 구간

## 5. 특징 그룹

초기 특징은 아래 5개 그룹으로 나눕니다.

### 가격/추세

- 최근 1/5/15/60분 수익률
- 고가/저가 돌파 여부
- 갭 상승/하락 상태

### 거래/유동성

- 거래량 급증 비율
- 거래대금 급증 비율
- 체결 수 변화

### 호가/미시구조

- 호가 불균형
- 스프레드
- 최우선 호가 잔량 변화

### 이벤트

- 최근 15분 뉴스 수
- 최근 60분 공시 수
- 이벤트 유형별 점수

### 심리 프록시

- 검색량 변화율
- 반응량 변화율
- 주의집중 점수

## 6. 학습 및 재학습 주기

### 초기 권장안

- 장중 추론: 실시간 또는 1분 주기
- 장후 라벨 확정
- 주 1회 정기 재학습
- 이벤트 장세 발생 시 수동 재학습 검토

### 이후 확장안

- 최근 1~3개월 가중치 확대
- 장세 레짐별 모델 분리
- 종목군별 보조 모델 분리

## 7. 온라인 운영 모델 구조

초기 운영에서는 모델을 3종으로 구분하는 것이 좋습니다.

### Candidate

- 실험 단계 모델

### Challenger

- 운영 환경에서 병행 평가 중인 모델

### Champion

- 현재 자동 모의주문 신호 생성에 사용하는 모델

## 8. 머신러닝에서 추가로 구체화가 필요했던 부분

전체 문서를 다시 보면, 이전까지는 머신러닝이 `모델링 전략` 수준에 머물러 있었습니다. 실제 개발 직전에는 아래 항목이 더 필요합니다.

1. 어떤 알고리즘을 1차 구현으로 고를지
2. 특징 생성 주기를 얼마로 할지
3. 예측 신호를 어떤 규칙으로 주문 신호로 바꿀지
4. 모의투자 성과를 모델 평가에 어떻게 반영할지

이 문서는 그 빈 부분을 메우기 위한 기준선입니다.

## 9. 초기 알고리즘 권장안

### 15분 모델

- 1순위: `LightGBM multiclass`
- 2순위: `XGBoost multiclass`

### 60분 모델

- 1순위: `LightGBM multiclass`
- 2순위: `CatBoost multiclass`

### 보조 모델

- Logistic Regression calibration

## 10. 고도화 순서

1. 가격/호가 모델 안정화
2. 공시/뉴스 특징 추가
3. 심리 프록시 특징 추가
4. 확률 보정
5. 메타 앙상블
6. 필요 시 텍스트 모델 별도 도입

## 11. 머신러닝 성공 기준

단순 정확도만 보면 부족합니다. 아래를 함께 봐야 합니다.

- balanced accuracy
- calibration
- 상위 신호 적중률
- 거래비용 반영 모의투자 성과
- 특정 종목 또는 특정 시간대 편향 여부
