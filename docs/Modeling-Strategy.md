# Modeling Strategy

## 1. 예측 문제를 먼저 좁힌다

처음부터 "주가를 맞춘다"라고 두면 범위가 너무 큽니다. 그래서 아래처럼 명확한 예측 과제를 병렬 또는 순차로 정의하는 것이 좋습니다.

| 과제 | 정의 | 추천 여부 |
| --- | --- | --- |
| 15분 방향 분류 | 향후 15분 수익률이 임계값 이상 상승/하락/중립인지 | MVP 추천 |
| 60분 방향 분류 | 향후 60분 기준 방향성 예측 | MVP 추천 |
| 당일 종가 방향 | 현재 시점 대비 당일 종가가 상방인지 | MVP 추천 |
| 변동성 폭발 탐지 | 향후 일정 구간 변동성이 급증할지 | 2단계 |
| 정확한 가격 회귀 | 특정 시점 가격 자체를 회귀로 예측 | 후순위 |

## 2. 차트 분석은 이미지보다 시계열 특징부터

사용자 요구에 `주가 그래프 분석`이 포함되지만, MVP에서는 차트 이미지를 직접 해석하기보다 `그래프 정보를 수치 특징으로 변환`하는 것이 더 안정적입니다.

### 우선 사용할 차트 특징

- 수익률: 1분, 5분, 15분, 60분
- 거래량 급증 비율
- VWAP 괴리율
- 고가/저가 돌파 여부
- 장중 변동성, ATR, 실현 변동성
- 체결 강도, 호가 불균형
- 갭 상승/하락 후 지속 여부

### 이후 검토할 확장

- 캔들 차트 이미지 기반 CNN/ViT
- 가격 시퀀스 인코더(Transformer, TCN)
- order book sequence model

## 3. 심리적 요인을 어떻게 수치화할지

사람의 심리는 직접 관측하기 어렵기 때문에, 아래와 같은 `프록시 변수`로 모델에 넣습니다.

| 심리 요인 | 프록시 예시 |
| --- | --- |
| 주의집중 | 검색량 급증, 뉴스 건수 급증, 조회/반응 증가 |
| 군집 행동 | 특정 키워드 감성 편중, 테마 동조화, 반응량 동시 폭증 |
| 공포/탐욕 | 급격한 변동성 확대, 급락/급등 후 반응량 급증 |
| 과민 반응 | 공시 직후 가격 변화가 과거 유사 이벤트보다 과도함 |
| 추격 심리 | 이미 오른 뒤 후행 반응량이 더 빠르게 증가함 |
| 앵커링 | 전일 종가, 최근 고점/저점, 라운드 가격대와의 거리 |

## 4. 모델 계층 권장안

### Layer 1: 베이스라인 가격/수급 모델

- 입력: 가격, 거래량, 호가, 장 상태, 기본 기술 지표
- 후보: LightGBM, XGBoost, CatBoost
- 목적: 복잡한 텍스트 없이도 기본 예측력을 확보

### Layer 2: 이벤트/텍스트 모델

- 입력: 공시 제목, 뉴스 제목/요약, 검색 반응 메타데이터
- 후보: 한국어 금융 텍스트 분류기, 사전학습 언어모델 파인튜닝
- 목적: 가격 데이터만으로 포착되지 않는 이벤트성 충격 반영

### Layer 3: 메타 앙상블

- 입력: Layer 1과 Layer 2의 점수 + 행동재무 특징
- 후보: Logistic Regression, LightGBM, calibration layer
- 목적: 각 신호의 강점을 결합하고 확률 보정 수행

## 5. 학습 데이터 설계 시 주의점

1. 분봉 기준 시계열과 이벤트 데이터를 같은 시간축으로 맞춥니다.
2. 뉴스/공시는 `게시 시각`을 기준으로 결합합니다.
3. 장전, 장중, 장후를 같은 분포로 보지 않습니다.
4. 액면분할, 거래정지, 이상 급등락 구간은 별도 처리합니다.
5. 미래 정보가 들어가는 누수 피처를 엄격히 차단합니다.

## 6. 평가 전략

### 오프라인 평가

- 워크포워드 검증
- 월별/장세별 성능 분해
- 종목별 성능 편차 분석
- precision, recall, balanced accuracy, PR-AUC

### 투자 관점 평가

- 상위 점수 종목의 hit rate
- 거래비용 반영 후 기대값
- 최대 낙폭과 회전율
- 경보 정확도와 노이즈 비율

### 운영 평가

- 데이터 지연 시 예측 품질 저하 정도
- 장중 특정 시간대별 안정성
- 특정 이벤트 유형에서의 실패 패턴

## 7. 설명 가능성 전략

모델이 높은 점수를 냈더라도 사용자는 `왜`를 알아야 합니다. 따라서 결과 화면에는 아래를 함께 보여주는 것이 좋습니다.

- 가격/호가 쪽 상위 특징
- 이벤트/반응 쪽 상위 특징
- 최근 30~60분 핵심 이벤트 타임라인
- 유사 패턴의 과거 예시

## 8. 권장 개발 순서

1. 가격/거래량/호가만으로 베이스라인 구축
2. 공시/뉴스 이벤트 결합
3. 검색량과 공개 반응 프록시 결합
4. 심리 프록시와 메타 앙상블 도입
5. 필요 시 텍스트 모델과 차트 인코더 확장
