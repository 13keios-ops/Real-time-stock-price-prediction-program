# 모델링 전략

## 역할

예측 문제를 어떻게 정의하고 어떤 순서로 모델링을 확장할지 설명하는 참고 문서다.

## 문제 정의

- 목표는 정확한 가격 자체보다 지정 수평선에서의 방향과 신호 품질이다.
- 1차 문제는 `15분 방향 분류`로 둔다.
- 이후 `60분 방향 분류`와 신뢰도 보정을 확장한다.

## 시작 전략

- 단순 모델로 전체 파이프라인을 먼저 고정한다.
- 현재 기준의 baseline은 centroid 기반 분류다.
- baseline에서 데이터 흐름과 평가 체계를 먼저 검증한다.

## 확장 순서

1. 가격/거래량/호가 기반 feature 안정화
2. label 품질 점검
3. challenger 모델 추가
4. 이벤트/NLP feature 결합
5. ensemble 또는 meta policy 검토

## 피해야 할 것

- 초기에 복잡한 모델부터 도입하는 것
- accuracy 하나만 보고 모델을 바꾸는 것
- 데이터 정합성이 불안정한 상태에서 실시간 전략을 튜닝하는 것
