# 실험 추적

## 역할

이 문서는 실험 기록과 비교 기준을 정리하는 참고 문서다.

## 현재 기록 대상

- 학습 실행
- 모델 평가
- 검증 꼬리구간 백테스트
- 워크포워드 백테스트
- 활성 모델 registry

## 기록 위치

- SQLite 저장 위치: `ml_training_runs`, `ml_model_evaluations`
- 파일: `runtime-data/ml/`, `runtime-data/reports/backtests/`
