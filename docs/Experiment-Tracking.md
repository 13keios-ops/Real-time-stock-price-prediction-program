# Experiment Tracking Plan

## 1. 목적

이 프로젝트에서는 "모델을 자주 바꾼다"보다 "무엇이 왜 좋아졌는지 남긴다"가 더 중요합니다.

따라서 모든 실험은 최소한 아래 질문에 답할 수 있어야 합니다.

1. 어떤 데이터와 특징을 썼는가
2. 어떤 라벨 정의를 썼는가
3. 어떤 검증 구간에서 성능이 나왔는가
4. 이전 모델보다 무엇이 좋아졌는가

## 2. 관리 대상

### 데이터 버전

- 종목 유니버스 버전
- 데이터 수집 기간
- 결측 보정 방식
- 이벤트 매핑 방식

### 특징 버전

- 특징 목록
- 계산 로직 버전
- 스케일링 또는 정규화 규칙

### 모델 버전

- 알고리즘 종류
- 하이퍼파라미터
- 학습 기간
- 사용 horizon

### 평가 버전

- 라벨 임계값
- 워크포워드 구간
- 평가 지표
- 거래비용 가정

## 3. 실험 로그에 남길 항목

각 실험마다 아래 정보를 기록합니다.

| 항목 | 설명 |
| --- | --- |
| `experiment_id` | 실험 ID |
| `created_at` | 생성 시각 |
| `objective` | 실험 목적 |
| `universe_version` | 종목군 버전 |
| `data_range` | 데이터 기간 |
| `feature_set_version` | 특징 버전 |
| `label_policy_version` | 라벨 규칙 버전 |
| `model_version` | 모델 버전 |
| `validation_scheme` | 워크포워드 설정 |
| `metrics_summary` | 주요 지표 |
| `decision` | 채택 / 보류 / 폐기 |
| `notes` | 해석 및 인사이트 |

## 4. 권장 버전 네이밍

초기에는 단순한 규칙이 좋습니다.

- 유니버스: `univ_top_value_30_v1`
- 특징: `feat_price_orderbook_v1`
- 라벨: `label_h15_h60_fixed_v1`
- 모델: `lgbm_h15_v1`

## 5. 모델 승격 규칙

오프라인에서 좋은 결과가 나와도 바로 운영 모델로 승격하지 않습니다.

권장 절차:

1. 베이스라인과 비교
2. 워크포워드 전 구간 확인
3. 월별 성능 편차 확인
4. calibration 확인
5. 챌린저로 운영 병행
6. 운영 로그까지 확인 후 승격

## 6. 예측 로그와 실험 로그 연결

실시간 예측 결과는 반드시 실험/모델 정보와 연결되어야 합니다.

최소 연결 키:

- `model_version`
- `feature_set_version`
- `label_policy_version`
- `universe_version`

이 연결이 있어야 나중에:

- 어떤 모델이 어떤 날 망가졌는지
- 어떤 특징 버전에서 성능이 나빠졌는지
- 어떤 종목군 구성에서 성능이 바뀌었는지

를 추적할 수 있습니다.

## 7. 실패 분석 템플릿

성능이 낮을 때는 아래 순서로 분석합니다.

1. 데이터 지연이나 결측이 있었는가
2. 특정 종목에만 실패가 집중되는가
3. 특정 시간대에만 실패하는가
4. 이벤트 직후에만 실패하는가
5. 신뢰도가 높은데도 틀렸는가

## 8. 챔피언/챌린저 운영

초기 단계부터 이 구조를 염두에 두는 것이 좋습니다.

### 챔피언

- 현재 운영 중인 모델

### 챌린저

- 새 특징이나 새 알고리즘이 포함된 후보 모델

비교 항목:

- 최근 1주 성능
- 최근 1개월 성능
- 고확신 신호 적중률
- 예측 분포 안정성

## 9. 운영 중 기록해야 할 인사이트

숫자만 남기면 부족합니다. 아래 같은 해석도 함께 남기는 것이 좋습니다.

- 뉴스 급증 특징은 장초반에만 유의미했다
- 호가 불균형 특징은 KOSDAQ에서 더 강했다
- 60분 라벨은 특정 종목군에서 과도하게 중립이 많았다
- 변동성 연동 임계값이 고정 임계값보다 calibration이 좋아졌다

## 10. 초기 구현 우선순위

개발을 시작하면 아래 수준부터 기록하면 충분합니다.

1. 모델 버전
2. 특징 버전
3. 라벨 버전
4. 워크포워드 결과 요약
5. 운영 예측 로그

그 다음 단계에서:

- 실험 비교 테이블
- 자동 리포트
- 성능 대시보드

를 붙이면 됩니다.
