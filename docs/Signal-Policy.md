# Signal Policy

## 1. 목적

이 문서는 머신러닝 예측을 실제 `모의주문 신호`로 바꾸는 초기 규칙을 정의합니다.

핵심 원칙:

1. 모델 예측과 주문 규칙을 분리합니다.
2. 초기 버전은 `long-only`로 시작합니다.
3. 초기 버전은 `당일 청산 중심`으로 운영합니다.
4. 강한 신호만 선별하고, 애매한 구간은 과감히 건너뜁니다.

## 2. 초기 전략 범위

### 전략 이름

- `paper_long_intraday_v1`

### 전략 성격

- 국내주식 장중 단기 추세 추종
- 상승 확률 기반 진입
- 손절/익절/시간청산 포함
- 공매도, 신용, 레버리지 미사용

### 현재 확정 선택안

- `기본형 진입/청산 규칙`을 현재 운영 기준으로 사용
- 신호가 애매하면 주문하지 않음
- 개장 직후 10~15분은 신규 진입 금지
- 장 마감 전 20~30분은 신규 진입 금지

## 3. 신호 생성 흐름

1. 모델이 `15분`, `60분` 확률 생성
2. 신호 필터가 최소 기준 통과 여부 판단
3. 리스크 엔진이 주문 가능 여부 판단
4. 통과 시 모의주문 생성

## 4. 초기 진입 규칙

현재 선택한 기본형 기준은 아래와 같습니다.

### 매수 진입 조건

모든 조건을 만족해야 합니다.

1. `15분 score_up >= 0.58`
2. `15분 score_up - score_down >= 0.18`
3. `60분 score_up >= 0.45`
4. `confidence >= 0.18`
5. 최근 `5분 거래대금 비율 >= 1.30`
6. 최근 호가 불균형이 극단적 매도 우위가 아님
7. 스프레드가 허용 범위 내
8. 데이터 지연/결측 경보가 없음

### 추가 차단 조건

다음 중 하나라도 해당하면 진입하지 않습니다.

1. 최근 악재성 공시 직후
2. 최근 예측이 급격히 흔들림
3. 동일 종목을 방금 청산함
4. 일일 손실 한도 도달
5. 장 마감 인접 구간

### 장중 시간대 규칙

- `09:00~09:10` 또는 `09:00~09:15`: 신규 진입 금지
- 중간 시간대: 신규 진입 허용
- `15:00~15:20` 또는 `15:00~15:30`: 신규 진입 금지

초기 구현 시에는 먼저 `09:00~09:15 금지`, `15:00~15:20 금지`를 기본값으로 두고 시작하는 것이 좋습니다.

## 5. 초기 청산 규칙

아래 중 하나라도 만족하면 청산합니다.

1. 손절선 도달
2. 익절선 도달
3. 최대 보유 시간 초과
4. 예측 신호 반전
5. 장 종료 전 강제 청산

### 초기 숫자 제안

- 손절: `-0.6%`
- 익절: `+0.8%`
- 최대 보유 시간:
  - 15분 신호 중심 진입: `20분`
  - 60분 보조 조건 포함 진입: `75분` 이내

초기에는 지나치게 오래 들고 가지 않는 것이 중요합니다.

현재는 위 숫자를 `1차 기본형 기준`으로 채택합니다. 개발 후 실험에서 조정합니다.

## 6. 포지션 사이징

### 초기 기준

- 종목당 진입 한도: 총 자산의 `5%`
- 동일 시점 최대 보유 종목 수: `3`
- 동일 종목 재진입 대기 시간: `10분`

### 이유

1. 모델 초기 성능이 불안정할 수 있습니다.
2. 모의투자 단계에서는 검증 데이터 확보가 더 중요합니다.
3. 과도한 포지션은 전략 오류를 증폭시킵니다.

## 7. 일일 리스크 한도

### 초기 한도

- 일일 손실 한도: `-2.0%`
- 연속 손실 거래 `3회` 발생 시 신규 진입 중단
- 데이터 지연 경보 발생 시 신규 진입 중단

## 8. 신호 품질 등급

초기에는 신호를 세 등급으로 나누는 것이 좋습니다.

### A등급

- 즉시 모의주문 가능

예시:

- 15분 상승 확률이 높고
- 60분도 우호적이며
- 거래대금과 호가 상태가 양호함

### B등급

- 관찰 대상, 즉시 주문은 보류

예시:

- 예측은 좋지만 신뢰도 부족
- 거래대금 증가가 약함

### C등급

- 주문 금지

예시:

- 데이터 품질 문제
- 장 마감 인접
- 악재 이벤트 직후

## 9. 초기 버전에서 하지 않는 것

1. 하락 베팅
2. 장기 보유
3. 동일 종목 반복 스캘핑
4. 뉴스 직후 즉시 공격 진입
5. 실전 주문 연동

## 10. 튜닝 우선순위

개발 후 가장 먼저 튜닝할 항목은 아래입니다.

1. `score_up` 기준
2. `confidence` 기준
3. 거래대금 급증 기준
4. 손절/익절 수치
5. 최대 보유 시간

## 11. 전략 성공 기준

이 전략은 아래를 만족하면 다음 버전으로 넘어갈 가치가 있습니다.

1. 거래비용 반영 후 양의 기대값 후보
2. 특정 종목 하나에만 성과가 몰리지 않음
3. 고확신 신호의 적중률이 의미 있게 높음
4. 손실이 리스크 한도 내에서 관리됨
