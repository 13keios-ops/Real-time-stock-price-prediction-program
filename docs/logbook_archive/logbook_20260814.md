# 작업 기록 요약: 2026-07-13~2026-08-14

이 문서는 `docs/logbook.md`에서 퇴역한 2026-07-13~2026-08-14 작업 기록의 요약이다.
세부 원문은 해당 시점 Git 이력과 당시 runtime report를 기준으로 한다.

## 운영과 수집

- 저장소 현재 문서를 역할별로 축약하고 구조 감사 도구를 추가했다.
- KIS approval-key 실패의 WebSocket 재시도와 watchdog 지수형 대기를 구현했다.
- serving decision ledger, complete lineage, raw minute gap, reconnect/storm 관측을 추가했다.
- 종가 동시호가 예상 gap과 정규장 예상 밖 공통 gap을 분리했다.
- broker paper sync 일반 실패와 rate limit에 bounded pause를 적용했다.

## Phase 0

- 과거 epoch 10개 유효 거래일은 matched 0일, mismatch 10일로 종료됐다.
- full-period account activity probe와 pagination 완결성을 추가했고, 2026-08-14 조회는 22페이지/329행에서 완결됐다.
- local-linked 320행과 broker-only 9행을 확인해 이전 divergence를 `external_or_unlinked_broker_activity`로 확정했다.
- 자동 align과 `SyncInitialCash`은 금지하고 clean baseline을 별도 승인 경계로 유지했다.

## 연구와 수익성

- E1/E5 snapshot timeout을 fail-closed로 처리하고 D드라이브 연구 snapshot 정책을 고정했다.
- 공통 비용 `krx-common-stock-2026-v1` 왕복 0.29%를 canonical 연구 비용으로 사용했다.
- buy-avoid, buy-rescue, hold-rescue는 절대 비용 후 양수 후보가 아니며 관측 전용으로 유지했다.
- `serving_decision_ledger`와 모델 artifact lineage를 수익성 판정의 필수 근거로 고정했다.
