- 보관일: `2026-04-11`
- 릴리스 버전: `0.2.0`

## 보관 요약

- 문서 중심 저장소 상태에서 실제 실행 가능한 Python 연구 골격까지 확장했다.
- KIS REST 현재가/호가 연동, WebSocket 파서, SQLite 실행 저장소, JSONL 기록기를 구현했다.
- 분봉, 특징, 라벨, centroid 기준 모델, 모델 등록부, 온라인 재생, 모의운용 상태 기록까지 연결했다.
- 검증 꼬리구간 백테스트와 워크포워드 백테스트를 추가했다.
- 실행 리포트, 백테스트 리포트, 워크포워드 리포트를 생성하도록 정리했다.
- 감시기 기준 버전 파일과 저장소 참여 설정을 정리하고 `0.2.0` 릴리스 체크포인트를 만들었다.

## 보관된 위험

- 실제 KIS WebSocket 장중 수신은 네트워크 가능한 장중 환경에서 별도 검증이 필요하다.
- 현재 머신러닝은 centroid 기준 모델 중심이므로 더 풍부한 도전자 모델 비교가 필요하다.
- 과거 주제 문서가 많아서 기준 문서와 참고 문서의 역할 분리를 더 명확히 해야 한다.
