# Project Roadmap

## 1. 현재 단계

현재는 `개발 착수 전 기획 구체화 단계`입니다. 이 단계의 목적은 아이디어를 넓히는 것이 아니라, 실제 개발 가능한 범위로 좁히는 것입니다.

현재까지 고정된 방향:

- 국내 주식 중심
- 실시간 데이터 수집 기반
- 머신러닝으로 예측 성능 개선
- 가격 데이터 단독이 아니라 뉴스/공시/반응/심리 프록시를 결합
- 자동매매보다 예측/경보/설명 가능한 대시보드 우선

## 2. 전체 단계 로드맵

### Phase 0. 문제 정의 고정

목표:

- 초기 종목 유니버스 확정
- 예측 수평선 확정
- 합법적으로 확보 가능한 데이터 소스 확정
- 성공 기준과 실험 기준 정의

완료 조건:

- 종목군, 타깃 라벨, 핵심 지표가 문서로 고정됨

### Phase 1. 데이터 기반 구축

목표:

- 실시간 시세/호가 수집기 설계
- 공시/뉴스/검색 데이터 수집 경로 설계
- 원본 저장, 정규화 저장, 특징 저장 구조 정의

산출물:

- 수집기 모듈 구조
- 종목 마스터 스키마
- 이벤트 표준 스키마
- 데이터 품질 점검 규칙

완료 조건:

- 장중 수집이 끊기지 않고 동작하는 최소 파이프라인 확보

### Phase 2. 베이스라인 모델 구축

목표:

- 가격/거래량/호가 기반 베이스라인 모델 구현
- 워크포워드 백테스트 환경 구축
- 예측 로그와 실제 결과 비교 구조 설계

산출물:

- 베이스라인 특징셋
- 베이스라인 모델
- 평가 리포트 템플릿

완료 조건:

- 단순 모멘텀/랜덤 기준보다 나은 일관된 성능 확보

### Phase 3. 이벤트 결합 모델 확장

목표:

- 공시, 뉴스, 검색량, 반응 프록시를 모델에 통합
- 이벤트 직후 변동성/방향성 예측 정확도 개선

산출물:

- 이벤트 특징셋
- 감성/주제/반응량 특징
- 가격 모델 + 이벤트 모델 메타 앙상블

완료 조건:

- 이벤트 구간에서 베이스라인 대비 유의미한 개선

### Phase 4. 실시간 추론/경보 시스템

목표:

- 최신 특징을 바탕으로 종목별 실시간 예측 점수 생성
- 경보 조건 정의
- 대시보드와 예측 근거 요약 제공

산출물:

- 추론 API
- 대시보드
- 경보 로그

완료 조건:

- 장중 운영 가능한 연구용 시스템 확보

### Phase 5. 정확도 개선 루프 운영

목표:

- 어떤 데이터와 특징이 실제 성능 개선에 기여하는지 추적
- 성능 하락과 드리프트를 감지
- 재학습 주기와 챔피언/챌린저 운영 체계 수립

산출물:

- 실험 이력 관리 규칙
- 재학습 정책
- 성능 모니터링 대시보드

완료 조건:

- 모델 개선이 감이 아니라 로그와 지표로 관리됨

## 3. 권장 1차 개발 범위

초기 개발은 아래 범위를 넘지 않는 것이 좋습니다.

### 종목 범위

- KOSPI/KOSDAQ 유동성 상위 30~50개

### 예측 문제

- 15분 방향 분류
- 60분 방향 분류

### 입력 데이터

- 실시간 가격/거래량
- 호가 요약 정보
- OpenDART 공시
- NAVER 뉴스 검색
- NAVER DataLab 검색량

### 출력

- 상방/하방/중립 점수
- 신뢰도
- 상위 영향 요인
- 실시간 경보

## 4. 정확도 개선을 위한 단계별 전략

정확도는 단순히 모델을 더 복잡하게 만든다고 올라가지 않습니다. 아래 순서로 개선하는 것이 안전합니다.

1. 수집 지연과 결측을 줄입니다.
2. 라벨 정의를 명확히 합니다.
3. 베이스라인 특징을 안정화합니다.
4. 이벤트 데이터를 시간 정렬해 붙입니다.
5. 심리 프록시 특징을 추가합니다.
6. 메타 앙상블과 확률 보정을 적용합니다.
7. 드리프트 감지와 재학습 주기를 운영합니다.

## 5. 개발 착수 전 남은 의사결정

1. 실시간 시세 API 공급자 확정
2. 장중 예측 수평선 우선순위 확정
3. 초기 종목군 확정
4. 텍스트 데이터 범위를 제목 중심으로 할지, 본문까지 확장할지 결정
5. 대시보드를 웹 기반으로 할지, 연구용 경량 UI로 시작할지 결정

## 6. 지금 단계의 목표

지금은 성급하게 코드를 쓰기보다 다음 질문들에 답이 가능한 수준까지 기획을 좁히는 것이 핵심입니다.

- 어떤 데이터를 언제 수집할 것인가
- 어떤 예측 문제를 먼저 풀 것인가
- 정확도가 좋아졌는지 무엇으로 판단할 것인가
- 실시간 운영에서 무엇이 실패할 수 있는가
