# Market Schedule Rules

## 1. 목적

이 문서는 한국 주식시장 시간 규칙을 시스템에 어떻게 반영할지 정의합니다.

중요한 이유:

1. 라벨 생성은 장중/장후 구분에 민감합니다.
2. 자동 모의주문은 시간대별 품질 차이가 큽니다.
3. 특수 일정일에는 거래시간이 바뀔 수 있습니다.

## 2. 현재 기본 거래 시간

KRX 공식 가이드 기준 일반 주식 정규 거래시간은 아래와 같이 확인됩니다.

- 정규장: `09:00~15:30`
- 호가 접수: `08:00~15:30`
- 시간외 시장도 별도 존재

현재 프로젝트는 초기 단계에서 `정규장 중심`으로만 다룹니다.

## 3. 프로젝트에서 사용할 세션 구분

### Pre-open

- `08:00~09:00`
- 용도: 시스템 기동, 전일 정리, 초기 데이터 점검
- 주문: 자동 모의주문 비활성화

### Regular Session

- `09:00~15:30`
- 용도: 실시간 예측, 신호 생성, 자동 모의주문

### After-hours

- `15:30 이후`
- 용도: 사후 평가, 로그 정리, 재학습 입력 정리
- 주문: 초기 버전에서는 비활성화

## 4. 자동 모의주문 시간대 규칙

현재 확정된 운영 기준은 아래와 같습니다.

### 신규 진입 금지 구간

- 장 시작 직후 `09:00~09:15`
- 장 마감 전 `15:00~15:20`

### 신규 진입 허용 구간

- `09:15~15:00`

### 포지션 정리 구간

- `15:20~15:30`

초기에는 이 규칙으로 충분합니다.

## 5. 라벨 생성 시간 규칙

15분/60분 라벨은 미래 구간이 장중 데이터로 완결되어야 합니다.

예시:

- `15분 라벨`은 최소 `15:15` 이전 시점까지만 생성
- `60분 라벨`은 최소 `14:30` 이전 시점까지만 생성

따라서 장 종료에 가까운 샘플은 자동 제외해야 합니다.

## 6. 특수 일정일 처리

KRX는 예외적으로 거래시간을 바꾸는 날이 있습니다.

예시:

- `2025-11-13` 대학수학능력시험일에는 정규장 시간이 `10:00~16:30`으로 변경된 공지가 있었습니다.

이 점 때문에 시스템은 장 시간을 하드코딩하면 안 됩니다.

## 7. 구현 원칙

### 하드코딩 금지

- `09:00~15:30`만 고정하지 않음
- 거래일별 세션 정보를 설정 파일 또는 캘린더 테이블로 관리

### 권장 구조

- `market_calendar` 테이블 또는 설정 파일
- 거래일별 open/close 시간 저장
- 예외일은 별도 override

## 8. 시장 일정 데이터 구조 제안

초기에는 아래 정도면 충분합니다.

| 컬럼 | 설명 |
| --- | --- |
| `trade_date` | 거래일 |
| `is_open` | 개장 여부 |
| `session_open` | 정규장 시작 |
| `session_close` | 정규장 종료 |
| `entry_start` | 신규 진입 시작 |
| `entry_end` | 신규 진입 종료 |
| `force_exit_time` | 강제 청산 시각 |
| `note` | 특이사항 |

## 9. 운영 체크포인트

1. 공휴일/휴장일 반영
2. 연말 휴장일 반영
3. 특수 일정일 거래시간 변경 반영
4. 시세는 오는데 장 상태가 닫힘으로 표기되는 경우 검출

## 10. 현재 기준으로 남겨둘 값

초기 기본값:

- `session_open=09:00`
- `session_close=15:30`
- `entry_start=09:15`
- `entry_end=15:00`
- `force_exit_time=15:20`

이 값은 시장 캘린더 예외가 없을 때만 적용합니다.
