# NLP Event Pipeline

## 역할

공시, 뉴스, 반응 데이터를 텍스트 이벤트로 받아 모델 입력으로 만드는 방향을 정리하는 참고 문서다.

## 기본 방향

- 초기에는 제목과 요약 기반의 단순 이벤트 파이프라인으로 시작한다.
- 텍스트 이벤트는 바로 주문 신호가 아니라 feature 보강용으로 사용한다.
- 종목 연결 신뢰도를 따로 기록한다.

## 초기 단계

- source 수집
- 중복 제거
- 종목 코드 매핑
- event type 분류
- sentiment 또는 polarity 점수화
- 15분/60분 집계 feature 생성

## 권장 원칙

- 실시간성보다 일관성과 추적 가능성을 우선한다.
- rule 기반 초기 버전을 먼저 만든다.
- 모델 기반 분류는 충분한 로그가 쌓인 뒤 비교한다.

## 저장 방향

- 원문 메타데이터
- 정규화 텍스트
- entity 매핑 결과
- event type
- sentiment score
- feature 반영 시각
