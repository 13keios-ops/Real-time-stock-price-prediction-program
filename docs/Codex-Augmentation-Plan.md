# Codex 보조 운영 계획

## 역할

이 문서는 Codex를 개발 보조와 운영 점검에 어떻게 붙일지 정리하는 참고 문서다.

## 현재 기준

- Codex는 코드 보조, 문서 점검, 로그 검토, 개선 제안에 사용한다.
- 프로그램 내부 기능이라기보다 외부 보조 루프 성격이 더 강하다.
- 로컬 활동 기록은 `runtime-data/` 아래에 남긴다.
- Codex가 확인할 주요 산출물은 아래와 같다.
  - 실행 리포트
  - 백테스트 리포트
  - 워크포워드 리포트
  - 감시기 상태와 앱 로그

## 현재 보류

- 프로그램 내부에 OpenAI 호출을 상시 내장하는 구조는 아직 보류한다.
- 자동 전략 변경이나 실전 주문 연동은 금지한다.
