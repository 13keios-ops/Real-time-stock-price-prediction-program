# 데이터 소스

## 역할

이 문서는 데이터 소스 선택 기준과 MVP 우선순위를 정리하는 참고 문서다.

## 우선 소스

- KIS Open API: 실시간 시세, 호가, snapshot
- OpenDART: 공시
- KRX 관련 소스: 보조 기준 데이터
- NAVER 계열 검색/트렌드 소스: 반응 proxy

## 현재 구현 상태

- 실제 코드 연결은 KIS 중심이다.
- 뉴스, 공시, 반응 데이터 파이프라인은 아직 설계 단계 성격이 더 크다.

## 원칙

- 공식 API를 우선한다.
- 약관과 비용 구조가 모호한 커뮤니티 직접 수집은 후순위로 둔다.
