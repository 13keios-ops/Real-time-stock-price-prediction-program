# 문서 아카이브

이 폴더는 현재 기준에서 퇴역했거나 너무 커진 운영 문서의 원문을 보존한다.

## 사용 규칙

- 현재 사실을 판단할 때 이 폴더를 기준으로 사용하지 않는다.
- 현재 기준은 `AGENTS.md`, `README.md`, `docs/STATUS.md`, `docs/Current-Implementation.md`, `docs/Production-Transition-Progress.md`를 따른다.
- 과거 결정의 맥락이나 수치 변화를 추적할 때만 읽는다.
- 아카이브 파일은 원문 보존이 목적이므로 최신 용어와 구조로 계속 고치지 않는다.
