# Product Requirements Document

## 1. 프로젝트 비전

국내 주식시장에 대해 다음 정보를 함께 고려하는 실시간 예측 시스템을 만든다.

- 실시간 가격, 거래량, 호가, 변동성
- 뉴스, 공시, 검색량, 공개 반응 변화
- 기술적 차트 패턴과 시장 미시구조
- 군집 심리, 과열/공포, 주의집중 같은 행동재무학 신호

목표는 "가격이 왜 움직일 가능성이 높은가"를 점수와 근거로 제시하는 것이다.

## 2. 해결하려는 문제

기존 개인 투자자의 의사결정은 보통 아래 문제를 가진다.

- 가격과 뉴스는 보지만, 둘을 시간축으로 정렬해서 판단하기 어렵다.
- 투자자 반응이 실제 수급/변동성으로 이어질지 구분하기 어렵다.
- 차트 신호가 단독으로는 잦은 오탐을 낸다.
- 사람의 심리적 편향 때문에 급등 추격, 공포 매도, 과신이 반복된다.

본 시스템은 이 신호들을 통합하여 `단기 변동 확률`을 추정하고, 사람의 주관적 판단을 보조한다.

## 3. 초기 사용자

초기 사용자는 `프로젝트 소유자 본인 또는 내부 연구 사용자`로 가정한다.

이 가정의 장점:

- 규제 리스크가 큰 투자 권유형 서비스로 바로 가지 않아도 된다.
- 제품 완성도보다 데이터 품질과 예측력 검증에 집중할 수 있다.
- 설명 가능한 내부 대시보드 형태로 빠르게 출발할 수 있다.

## 4. MVP 범위

### 포함

- 유동성 높은 국내 주식 종목군에 대한 실시간 모니터링
- `15분`, `60분`, `당일 종가` 기준 방향 또는 변동성 예측
- 뉴스/공시/검색/반응 급증 탐지
- 차트 기반 기술적 특징 추출
- 심리/행동재무 프록시 특징 생성
- 예측 결과와 핵심 근거 요약
- 경보와 예측 로그 저장

### 제외

- 초단타 초저지연 HFT 수준 예측
- 자동 주문 실행
- 비공개/약관 위반 가능성이 있는 데이터 수집
- 투자 권유 문구, 추천 종목 공개 서비스

## 5. 핵심 사용자 시나리오

### 시나리오 A: 장중 급등 후보 탐지

사용자는 장중 특정 종목의 거래량 급증과 뉴스 노출 증가를 본다. 시스템은 호가 불균형, 체결 강도, 뉴스 반응, 검색량 급증을 결합해 `15분 내 상방 확률`을 계산하고 근거를 보여준다.

### 시나리오 B: 공시 이후 과민 반응 식별

공시가 나온 뒤 급락 또는 급등이 발생했을 때, 시스템은 과거 유사 공시와 비교해 과잉 반응 가능성을 평가하고 반전 또는 추세 지속 가능성을 표시한다.

### 시나리오 C: 심리 과열 구간 감지

특정 테마가 급부상할 때 검색량과 반응량은 폭증하지만 실제 체결 구조가 약하면, 시스템은 `주의집중은 높지만 추세 품질은 낮다`는 경고를 준다.

## 6. 핵심 출력

- 종목별 예측 점수
- 상방/하방/중립 분류
- 신뢰도 점수
- 영향 상위 요인 3~5개
- 최근 이벤트 타임라인
- 알림 이력과 예측 성과 로그

## 7. 성공 기준

### 제품 기준

- 장중 주요 종목의 상태를 한 화면에서 확인할 수 있어야 한다.
- 예측 결과마다 최소한의 설명 근거가 있어야 한다.
- 데이터 지연이나 누락 여부를 운영자가 확인할 수 있어야 한다.

### 모델 기준

- 단순 가격 모멘텀 베이스라인보다 일관된 개선이 있어야 한다.
- 워크포워드 검증에서 특정 구간에만 과적합되지 않아야 한다.
- 거래비용을 고려한 모의 운용 기준에서 양의 기대값 후보가 보여야 한다.

### 데이터 기준

- 실시간 시세 수집 지연은 낮게 유지되어야 한다.
- 이벤트성 데이터는 게시 시각 기준으로 정확히 정렬되어야 한다.
- 종목코드, 액면분할, 거래정지 등 메타데이터 보정이 일관되어야 한다.

## 8. 주요 리스크

1. 데이터 합법성
2. 시간 정렬 실패로 인한 누수
3. 특정 장세에만 맞는 과적합
4. 반응 데이터의 노이즈 과다
5. 설명은 그럴듯하지만 실전 성능이 약한 모델

## 9. 제품 원칙

1. 공식 API 우선
2. 설명 가능한 신호 우선
3. 베이스라인 선행, 복잡도 후행
4. 실시간 운영 가능성을 고려한 설계
5. 투자 조언이 아니라 의사결정 보조 도구로 포지셔닝
