## 현재 저장소 상태

- Git 저장소는 생성되어 있으나 작업 파일은 사실상 비어 있습니다.
- 기존 `*.md` 문서는 존재하지 않았습니다.
- 코드 디렉터리, 데이터 디렉터리, 테스트 구조, 실행 스크립트가 아직 없습니다.
- 따라서 이번 단계의 "md 파일 검토"는 기존 문서 리뷰보다는 `프로젝트 기준 문서 신규 작성`이 중심입니다.

## 핵심 판단

1. 이 프로젝트는 일반적인 시계열 예측보다 어렵습니다.
2. 이유는 가격 데이터만으로는 부족하고, `뉴스/공시/반응/심리`를 시간 정렬한 멀티모달 파이프라인이 필요하기 때문입니다.
3. 그래서 처음부터 거대한 모델을 만들기보다 `문제 정의 -> 데이터 합법성 -> 베이스라인 -> 실시간화` 순서로 가야 합니다.

## 권장 우선순위

1. 합법적으로 확보 가능한 데이터만으로 MVP를 먼저 구성합니다.
2. 실시간 시세/호가 + 공시 + 뉴스 + 검색 관심도 조합으로 1차 모델을 만듭니다.
3. 커뮤니티 크롤링은 약관, robots, 라이선스 검토 후 별도 단계로 분리합니다.
4. 처음부터 딥러닝 단일 모델 하나에 올인하지 말고 베이스라인 앙상블을 먼저 안정화합니다.
