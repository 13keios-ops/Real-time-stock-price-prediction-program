# 저장소 전용 Skill

이 폴더는 이 저장소에서 반복적으로 쓰는 Codex skill 원본을 두는 자리다.

현재는 canonical skill 본문보다 실행 스크립트와 운영 문서가 먼저 존재한다.
반복 절차가 충분히 안정되면 이 위치에서 skill로 승격해 관리한다.

skill 후보 관리는 `docs/Codex-Operating-Feedback.md`의 판정 기준을 따른다.

- 모든 작업에 항상 적용되는 금지 규칙은 먼저 `AGENTS.md`에 둔다.
- 절차가 3회 이상 반복되고 누락이 잦으면 skill 후보로 올린다.
- 실행 순서가 완전히 결정적이면 skill보다 스크립트나 테스트로 잠근다.
- skill로 승격할 때는 최소한의 `SKILL.md`와 필요한 reference/script만 둔다.
